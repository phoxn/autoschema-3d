# АвтоСхема 3D — прототип

Интерактивный 3D-учебник для автомехаников: схематичная модель Hyundai Solaris I (2010–2017, 1.6 G4FC),
пошаговые инструкции замены деталей с подсветкой того, что нужно открутить, и описания деталей с признаками неисправностей.

- `parts.js` — детали и их расположение (по фото руководства по ремонту, формы упрощены)
- `ops.js` — операции замены (порядок работ по руководству на carpedia.club, ссылки внутри)
- `app.js` — 3D-движок на Three.js, `index.html` — интерфейс

Запуск локально: `python -m http.server 8765`, затем открыть http://localhost:8765

Данные механиком не проверены. Моменты затяжки сверяйте с заводским руководством.
